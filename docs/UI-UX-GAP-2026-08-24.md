## Estimator companion design note

The right dock is a **flex column with its own scroller**. The mode panel (`perimeter-panel`) and estimator (`estimator-panel`) are siblings — not nested. When both need height:

1. Mode panel gets `flex: 1 1 auto; minHeight: 0` and owns the checklist.
2. Estimator opens as **compact** — one row: `Provisional · N items · $total ▾`.
3. Operator expands to itemized card; dock scroll absorbs overflow — no geometric overlap.

Binding: `docs/GOLD-STANDARD-2026.md` Phase 3 (itemized fit-sheet is ambient, not Step 0 primary chrome).
