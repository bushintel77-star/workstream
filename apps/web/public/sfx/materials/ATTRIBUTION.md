# Material design Foley — attribution

Tiny interaction bites for placing / painting studio concepts.
Kept quiet and short for a design product (not arcade game UI).

## Mapping (studio types → family)

| Family | Studio types | Intent |
|--------|--------------|--------|
| wood | deck, hedge | Plank / timber knock |
| stone | paving | Stone / paver tap |
| brick | (paint paving variants) | Light brick clack |
| soil | lawn, bed, frenchdrain | Spade / dig bite |
| softscape | canopy, feature, exist | Soft leaf / grass |
| soft | fallback | Quiet generic place |
